     - High

     - High
   * - Layer 2 NLI contradiction check
     - REQ-CASC-L2-01
     - The NLI check runs only when both the RAG context and the response are non-empty; otherwise `checked=False`
     - Medium
   * - 
     - REQ-CASC-L2-02
     - A clear factual contradiction is labelled `contradiction`, a consistent response is not, and the score is a probability in [0, 1]
     - Medium
   * - 
     - REQ-CASC-L2-03
     - The NLI check is skipped for echo-rejected rows and runs exactly once for a non-echo row with RAG on
     - Medium
   * - 
     - REQ-CASC-L2-04
     - Layer 2 gates responses on a threshold calibrated on real RAG-enabled data
     - Medium
   * - 
     - REQ-CASC-L2-05
     - Sentiment and toxicity classifiers score each response
     - Low
   * - Structured judge
     - REQ-CASC-L3-01
     - The judge parses real JSON into `{verdict, confidence, rationale}`: a clear pass and a clear fail (CLAUDE.md section 4)
     - High
   * - 
     - REQ-CASC-L3-02

     - High
   * - 
     - REQ-CASC-L3-03

   * -
